LPIPS：学习感知图像块相似度

LPIPS（Learned Perceptual Image Patch Similarity）是一种基于深度学习的全参考图像质量评价指标。它利用预训练分类网络的多层特征差异，模拟人类对图像相似度的感知判断，与主观评分高度一致。

核心要点：LPIPS 输出一个感知距离，数值越小表示两张图越相似（感知质量越好）。

一、算法原理

1.1 为什么需要 LPIPS？

  • PSNR/SSIM 的局限：传统指标只比较浅层像素差异，无法捕捉深层语义和纹理的失真，经常出现“分数高但人眼看着差”的情况。
  • 深度特征的自然优势：在 ImageNet 上训练的分类网络（如 AlexNet、VGG）的中间层会自动提取边缘、纹理、物体部件等层次化特征，与人类视觉通路相似。
  • 学习人类判断：通过大量人类 2AFC 判断数据训练一个轻量加权层，将多层特征差异融合为感知距离。

1.2 与常用指标的对比

指标核心机制与人眼一致性
PSNR像素级 MSE差
SSIM手工设计的亮度、对比度、结构中等
LPIPS深度网络特征差异 + 学习权重优秀

二、算法具体步骤

给定参考图像 $x$ 和失真图像 $x_0$，LPIPS 的计算分为四步：

  1. 提取多层特征：将 $x$ 和 $x_0$ 分别送入同一个预训练网络（如 AlexNet），取出 $L$ 个中间层的特征图。对于第 $l$ 层，得到两个形状为 $C_l \times H_l \times W_l$ 的张量： $$\phi_l(x), \quad \phi_l(x_0)$$
  2. 计算逐通道差异（对每一层 $l$）：
    1. 逐元素相减并平方： $$\text{Diff}_l = \big( \phi_l(x) - \phi_l(x_0) \big)^2$$
    2. 空间平均：对每个通道 $c$ 求空间均值，得到一个长度为 $C_l$ 的向量 $\mathbf{d}_l$： $$d_l^c = \frac{1}{H_l W_l} \sum_{h,w} \text{Diff}_l(c, h, w)$$
    3. 通道加权求和：用该层预先训练好的权重向量 $\mathbf{w}_l$ 与 $\mathbf{d}_l$ 做点积，得到该层的感知距离： $$d_l = \mathbf{w}_l \cdot \mathbf{d}_l = \sum_{c=1}^{C_l} w_l^c \cdot d_l^c$$
  3. 跨层求和：将所有层的距离相加得到最终 LPIPS 分数： $$\text{LPIPS}(x, x_0) = \sum_{l=1}^{L} d_l$$ 通常 $L = 5$（AlexNet 的 conv1 至 conv5）。
关键点：特征提取网络完全冻结，只有通道权重 $\mathbf{w}_l$ 是可学习的参数，这些权重通过训练得到，推理时直接使用。

三、训练方法

3.1 训练数据：BAPPS 数据库

训练数据采用三元组形式，来自人类 2AFC（二选一强迫选择）实验：

  • 参考图 $x$
  • 两张失真图 $x_A$ 和 $x_B$
  • 人类标签 $y \in \{0,1\}$：$y=1$ 表示人认为 $x_A$ 比 $x_B$ 更像 $x$；$y=0$ 则相反。

这种方式避免了绝对评分的不稳定性，人类只需判断“谁更像”。

3.2 训练流程

  1. 前向传播：对每一组训练样本 $(x, x_A, x_B, y)$，分别计算两个距离： $$d_A = \text{LPIPS}(x, x_A), \quad d_B = \text{LPIPS}(x, x_B)$$
  2. 转化为概率：用 Sigmoid 函数将距离差映射为“A 更近”的概率： $$\hat{p} = \frac{e^{-d_A}}{e^{-d_A} + e^{-d_B}} = \sigma(d_B - d_A)$$ 若 $d_A < d_B$，则 $\hat{p} > 0.5$，模型倾向于 A 更像原图。
  3. 计算损失：二元交叉熵损失，使预测概率 $\hat{p}$ 逼近真实标签 $y$： $$\mathcal{L} = -y \log(\hat{p}) - (1-y) \log(1-\hat{p})$$
  4. 反向传播：损失仅对通道权重 $\mathbf{w}_l$ 求导，特征提取网络保持冻结。使用 Adam 或 SGD 更新权重。

3.3 训练细节与技巧

  • 网络选择：常用 AlexNet（轻量）或 VGG（更准），均在 ImageNet 上预训练。
  • 层数：取 5 个中间层（如 AlexNet 的 conv1～conv5），兼顾浅层纹理和深层语义。
  • 权重初始化：所有通道权重初始化为 1，即初始时退化为简单的通道平均差异。
  • 参数量：AlexNet 版本仅约数千个参数，训练极快且不易过拟合。

3.4 为什么只训练通道权重？

预训练的分类网络已经具备了强大的视觉特征层次结构，直接修改卷积核会破坏这种特性。我们只需要学习“当第 $l$ 层的第 $c$ 个通道发生多大变化时，人眼会敏感”即可。这相当于在固定特征空间上学习一个最优的感知度量，既保留了泛化性，又针对人类感知进行了校准。

四、总结与应用

  • 推理使用：直接输入参考图和待测图，输出一个距离值（越小越好）。
  • 典型场景：图像超分辨率、压缩、去噪、风格迁移等的感知质量评估。
  • 常用实现：Python 的 lpips 库，一行代码即可计算。
