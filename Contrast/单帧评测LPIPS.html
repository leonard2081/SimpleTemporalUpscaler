LPIPS：学习感知图像块相似度

LPIPS（Learned Perceptual Image Patch Similarity）是一种基于深度学习的全参考图像质量评价指标。它通过预训练网络的多层特征差异，模拟人类对图像相似度的感知判断，与主观评分高度一致。

一、算法原理

1.1 核心思想

  • 利用深度网络的内在感知能力：在 ImageNet 上训练的分类网络（如 AlexNet、VGG）的中间层天然提取了边缘、纹理、物体部件等多层次特征，这些特征与人类视觉系统的层次化处理高度对应。
  • 不直接使用分类结果，而是比较两张图在多个中间层的内部特征图差异。
  • 通过学习各通道的重要性权重，将各层差异融合为一个与人类主观评分（MOS）高度相关的距离度量。

1.2 与 PSNR/SSIM 的区别

  • PSNR：纯像素误差，与感知偏差大。
  • SSIM：手工设计的亮度、对比度、结构三要素，缺少高层语义。
  • LPIPS：端到端学习，从数据中自动获得符合人眼感知的相似度标准。

1.3 输出含义

LPIPS 输出一个感知距离 \(d(x, x_0)\)，代表失真图 \(x_0\) 相对于参考图 \(x\) 在感知上有多“不像”。数值越小，表示两张图越相似，质量越好。

二、算法具体步骤

给定参考图像 \(x\) 和待评估图像 \(x_0\)，计算流程如下：

  1. 选择预训练网络：通常使用 AlexNet 或 VGG，固定所有卷积层权重（作为特征提取器，不参与训练）。
  2. 提取多层特征：将 \(x\) 和 \(x_0\) 分别送入同一个网络，取出 \(L\) 个中间层的特征图（如 AlexNet 的 conv1～conv5）。
    对于第 \(l\) 层，得到两个形状为 \(C_l \times H_l \times W_l\) 的三维张量： \[ \phi_l(x), \quad \phi_l(x_0) \]
  3. 逐通道计算差异（针对每一层 \(l\)）：
    1. 逐元素相减并平方： \[ \text{Diff}_l = \big( \phi_l(x) - \phi_l(x_0) \big)^2 \]
    2. 空间平均：对每个通道 \(c\)，将其 \(H_l \times W_l\) 个空间位置的差异值取平均，得到该通道的差异标量： \[ d_l^c = \frac{1}{H_l W_l} \sum_{h,w} \text{Diff}_l(c, h, w) \] 这一步将 \(C_l \times H_l \times W_l\) 的差异图压缩为长度为 \(C_l\) 的向量 \(\mathbf{d}_l\)。
    3. 通道加权求和：使用该层预先训练好的权重向量 \(\mathbf{w}_l\)（长度也为 \(C_l\)）与 \(\mathbf{d}_l\) 做点乘，得到该层的感知距离： \[ d_l = \mathbf{w}_l \cdot \mathbf{d}_l = \sum_{c=1}^{C_l} w_l^c \cdot d_l^c \] 权重 \(w_l^c\) 反映了第 \(l\) 层第 \(c\) 个通道对人类感知的重要程度。
  4. 跨层求和：将所有层计算出的距离直接相加，得到最终 LPIPS 分数： \[ \text{LPIPS}(x, x_0) = \sum_{l=1}^{L} d_l \] 通常 \(L = 5\)（AlexNet 的 conv1 到 conv5）。

注意：整个计算过程中，特征提取网络完全冻结，没有任何可训练参数；唯一可训练的是各层的通道权重 \(\mathbf{w}_l\)，这些权重在训练阶段已确定，推理时直接使用。

三、训练方法

3.1 训练数据

训练数据来源于人类主观判断数据库，最常用的是 BAPPS (Berkeley Adobe Perceptual Patch Similarity)。数据格式为三元组：

  • 参考图像 \(x\)
  • 两张失真/处理后图像 \(x_A\) 和 \(x_B\)
  • 人类标签 \(y\)：\(y=1\) 表示人类认为 \(x_A\) 比 \(x_B\) 更像 \(x\)；\(y=0\) 则相反。

这种收集方式称为 2AFC（二选一强迫选择），避免了对绝对分数的标尺依赖。

3.2 训练流程

训练目标是学习各层的通道权重 \(\mathbf{w}_l\)，使得模型输出的距离相对大小与人类判断一致。

  1. 前向传播，计算两个距离： 将 \(x, x_A, x_B\) 分别送入同一个特征提取网络，按第二章的步骤计算出两个感知距离： \[ d_A = \text{LPIPS}(x, x_A), \quad d_B = \text{LPIPS}(x, x_B) \]
  2. 将距离差转化为概率： 用 Sigmoid 函数将两个距离的差映射为“模型认为 A 更近”的概率： \[ \hat{p} = \frac{e^{-d_A}}{e^{-d_A} + e^{-d_B}} = \sigma(d_B - d_A) \] 当 \(d_A < d_B\) 时，\(d_B - d_A > 0\)，\(\hat{p} > 0.5\)，模型倾向于 A 更像原图。
  3. 计算损失： 使用二元交叉熵损失，使 \(\hat{p}\) 逼近真实的人类标签 \(y\)： \[ \mathcal{L} = -y \log(\hat{p}) - (1-y) \log(1-\hat{p}) \]
  4. 反向传播，更新权重： 损失仅对通道权重 \(\mathbf{w}_l\) 求导（特征提取网络冻结），使用 SGD 或 Adam 优化器更新权重。

3.3 训练细节

  • 网络选择：常用 AlexNet 或 VGG16，在 ImageNet 上预训练。
  • 层数：通常取 5 个中间层（AlexNet 的 conv1～conv5）。
  • 权重初始化：各层通道权重初始化为 1 或均匀值，表示所有通道同等重要。
  • 训练规模：BAPPS 包含数万对训练样本，足以训练稳定的权重。
  • 最终效果：训练好的权重在不同数据集和失真类型上泛化良好，LPIPS 与人类 MOS 的相关系数显著高于 PSNR/SSIM。

3.4 为什么只训练通道权重？

特征提取网络已经具备强大的层次化视觉特征；我们只需学习“当某一层、某一通道的特征发生多大变化时，人眼会认为‘不像’”。这种设计参数量极少（AlexNet 版本仅约几千个参数），训练快速且不易过拟合，同时保留了特征空间的固有感知结构。

四、使用与评价

训练完成后，推理时直接调用固定的网络和权重，输入参考图和待测图即可得到距离分数。该分数越小表示感知质量越好。在超分辨率、图像压缩、去噪等任务中，LPIPS 已成为最受认可的感知质量指标之一。
